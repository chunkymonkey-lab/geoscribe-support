Common Questions

Controls and features vary by installed version. The version 1.3 beta is being prepared for App Store review; its subscription features are not yet a public release.

How do GPS recording and voice notes differ?

The route recording control starts and pauses the GPS trail. The separate microphone control records a voice note. In the latest beta, pausing keeps the survey open; Finish & Export captures the final map and opens report choices.

Recording and transcription are separate. On-device speech recognition is attempted where available, with Apple-server fallback when local recognition cannot complete. Review transcripts for errors. A failed transcript does not mean the original audio has been deleted.

My location is missing or appears out of date

Check iPhone Settings > Privacy & Security > Location Services, then GeoScribe Pro. Allow location access and enable Precise Location if you need it. Return to the app and use its location control to centre the map.

GPS quality varies with surroundings and reception. A map position is an estimate, not a certified survey measurement. If the issue continues, send support your app build, permission settings and a description of when the location stopped updating.

Can an HTML report be opened without importing data?

In versions that offer interactive HTML export, the report contains its exported survey data and selected available media. No separate survey-data import is required. When a street-map extract is successfully embedded, it can appear beneath the route without internet. Optional online layers and external imagery links still require internet.

For offline report maps, download the required area in Settings > Offline map areas and wait for Saved. Export a survey inside that area. If an alert says the street map could not be embedded, do not assume the basemap will work offline. Keep the complete ZIP package together when sharing one.

If an email or Files preview shows a blank page, save the report and open it in a browser that supports interactive HTML. Do not upload a sensitive survey to a public website to view it.

I bought the paid app. What happens with version 1.3?

The planned version 1.3 release is designed to retain Pro access for qualifying earlier paid buyers when Apple verifies their original purchase. TestFlight and development receipts do not establish an earlier paid purchase.

If you are testing the beta, use Settings > GeoScribe > Plan for access information. Report any access error with the build number and the message shown. Do not send an unredacted receipt. The existing public app remains a paid release until the new version is released.

How do I restore or cancel a subscription?

For a version with subscriptions, use Restore Purchases on the Pro screen. Use Manage Subscriptions there, or Apple Account subscription settings, to manage renewal.

Deleting the app does not cancel a subscription. Features and prices shown during beta testing are not a promise that the subscription is publicly available.

Can I continue a driving survey on foot?

In the latest beta, Pause Driving offers Continue on Foot or Pause GPS Recording within the same survey. Resume Driving replans from the current location and requires Go before guidance starts. Finish and export on iPhone.

Prepare or edit surveys while safely stopped. Road signs and restrictions take precedence over mapped guidance. Coverage planning cannot guarantee current closures, road access or the shortest possible route.

How do I delete a saved survey or offline map?

Use the saved-survey controls to delete a named job, or Settings > Offline map areas to delete a downloaded map area where that feature is available.

Deleting a saved job is not a guarantee that every linked photograph, recording, export or backup has also been deleted. Preserve records you need before removing app data, and manage previously shared copies separately.

How do I ask a privacy question?

Email geoscribe.support@icloud.com. Start with a description of your request rather than sending survey files or identification documents.

This support website uses no analytics scripts, contact forms or external map embeds. It is hosted by GitHub Pages, which may process connection information under the GitHub Privacy Statement. Read the GeoScribe Privacy Policy and Terms of Use for version 1.3.
